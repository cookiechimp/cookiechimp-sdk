# CookieChimp Consent SDK 1.2.0

Release candidate, not yet published. All nine packages share version 1.2.0.

## React Native and Expo

- Add `@cookiechimp/react-native` with native consent banners and preferences
  using dashboard copy, categories, vendors and styling.
- Use connected configuration or a bundled offline config, persist choices in
  AsyncStorage, and queue consent records for delivery when online.
- Control analytics and advertising SDKs with vendor callbacks and reopen privacy
  preferences from app settings through the imperative API or React hooks.
- Run core consent without browser APIs, with native storage, iOS/Android record
  metadata and an explicit retry API for app foreground and reconnect handling.

## Web SDK improvements

- Block configured tracking images, including detached images and responsive
  candidates, through the optional dynamic controller until consent allows them.
- Reduce the additional size of connected sync while retaining the existing
  marginal bundle size target.
- Keep consent logging queues intact when a stopped log finishes an old request.
- Match configured branding in the platform banner and preferences.
- Expand US state privacy-format encoding for Minnesota, Maryland, Indiana,
  Kentucky and Rhode Island.

## Publication status

Current npm `latest` remains 1.1.0 for the eight existing packages. The new native
package is not yet on npm. Native device execution, live backend verification and
initial npm setup remain required before publication; see [release status](../remaining-work.md).
